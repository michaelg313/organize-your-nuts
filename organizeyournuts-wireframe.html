OrganizeYourNuts — Lo-Fi Wireframe rev: vehicle filter on Kits overview · systems collapsed

Restructured Site — Wireframe Set (revised)

Seven page templates below, numbered ①–⑦. Toggle Desktop / Mobile above; every section is annotated.

What changed vehicle selection moved up → system pages collapsed

The customer now sets Make / Model / Year / Engine on the Hardware Kits overview page itself, instead of on individual system pages. Consequences reflected below:
  • The 5 system pages are gone as pages. Engines, Transmissions, Steering & Suspension, Diff/Axle, Body & Trim are no longer separate URLs. The old "System page template" is removed — its filter + results grid are now the Hardware Kits overview.
  • Systems survive as a results facet, not sitemap nodes — an optional chip row to narrow the filtered kits to one category.
  • Template count 8 → 7. Storage (overview + sub-category), Cart, Checkout, and About/Contact are unchanged.
  • The old open question is resolved: "does Make/Model/Year persist across system pages?" no longer applies — the filter is set once, on one page.
